# spelling-book

Look-Cover-Write-Check spelling practice for iPad and Apple Pencil.

Live app: https://ozanilhan79.github.io/spelling-book/

On the iPad, open the link in Safari, then Share → Add to Home Screen. It then opens full screen like an app. Progress is saved only on that iPad.

The files here are built from `rana-spelling/` in the `ringlight` repo with `python3 build.py`; edit the source there, rebuild, and copy `app/*` here.
